About This Platform

This project combines crop disease classification and farm economics planning in one place.

Core Modules

  • FastAPI backend with strict Pydantic validation
  • CNN-based disease prediction pipeline with optional XAI layer selection
  • Recommendation engine with likely cause, recovery, and spray guidance
  • Cost model with land, labor, water, input cost, and production factors
